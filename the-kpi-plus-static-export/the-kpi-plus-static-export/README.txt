The KPI Plus — Static HTML Export
=================================

This folder is a static mirror of the deployed The KPI Plus website.
It includes the localized HTML pages listed in sitemap.xml, JavaScript, CSS, fonts, images, and other required assets.

To preview locally:

  python3 -m http.server 8080

Then open:

  http://localhost:8080/

The export preserves the website route structure. Form submissions, analytics, server-side APIs, authentication, and other server-dependent functionality require the original hosted website and will not operate as fully static features.
