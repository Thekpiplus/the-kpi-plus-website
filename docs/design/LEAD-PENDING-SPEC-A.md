## นิยาม

- **งานค้าง** = `!archived && !isWon` (ยังปิดการขายไม่ได้)
- ขอบเขต: `all` · `website` (ฟอร์มเว็บไซต์) · `other` (ช่องทางอื่นนอกจากเว็บไซต์)
- สาเหตุ (นับซ้อนได้): เกินกำหนดติดต่อ · ถึงกำหนดวันนี้ · รอลูกค้าตอบกลับ · ยังไม่เคยติดต่อ · ยังไม่มอบหมายผู้ดูแล
- มูลค่า 0 / null = «ยังไม่ประเมิน»
- ซ่อน KPI ระดับระบบ — ใช้โดนัท + กราฟแท่ง + การ์ดสาเหตุแทน
- กราฟ: โดนัท = น้ำหนักการติดป้าย (นับซ้อนได้) · แท่ง/% = เทียบจำนวนงานค้างจริง · คลิกกรอง
- ห้าม modal / alert / confirm / toast · URL เป็น SSOT
